# Privacy Policy for Unknown Unknowns

**Effective date:** November 4, 2026

Unknown Unknowns is a skills-only ChatGPT plugin published by Jack Tom and maintained in the public repository `shenzhongchao/unknown-unknowns`.

## What this plugin does

The plugin provides reusable instructions for examining problem frames, assumptions, evidence gaps, failure modes, outside views, and reality-facing probes. This version does not operate an external server, database, analytics service, account system, or payment system.

## Data collected by the publisher

The publisher does not receive, collect, store, sell, or share the prompts, files, conversation content, or outputs that you use with this plugin.

Because the plugin runs inside ChatGPT, OpenAI may process your interactions according to the terms, privacy policy, data controls, and product settings that apply to your ChatGPT account. Those systems are operated by OpenAI, not by the publisher of Unknown Unknowns.

## External links

The plugin listing and documentation may link to the public GitHub repository and its issue tracker. GitHub processes visits to those pages under GitHub's own policies.

## Retention and deletion

The publisher keeps no plugin-specific user records to retain or delete. For conversation history or other information handled by ChatGPT, use the controls provided by OpenAI. For information you voluntarily post in the public GitHub issue tracker, edit or delete it through GitHub where available, or request help through the support page.

## Sensitive information

Do not include passwords, API keys, private customer data, medical records, or other sensitive information in public GitHub issues. Use redacted examples when requesting support.

## Changes

This policy may be updated when the plugin's data practices or capabilities change. Material changes will be reflected in this file and the plugin release notes.

## Contact and support

For questions about this policy, use the public support process described in [SUPPORT.md](SUPPORT.md).
