# Support for Unknown Unknowns

Unknown Unknowns is an open-source, skills-only ChatGPT plugin.

## Get help

Use the repository's public issue tracker:

- Report a bug or unexpected behavior.
- Suggest an improvement to a skill or workflow.
- Share a reproducible example where the plugin overreached, missed an important frame, or designed a weak probe.
- Ask a question about installation, packaging, or expected behavior.

Open an issue at:

`https://github.com/shenzhongchao/unknown-unknowns/issues`

## What to include

A useful report contains:

1. the prompt or decision context, with sensitive details removed;
2. the ChatGPT or agent environment where it occurred;
3. the output you received;
4. what you expected instead;
5. whether the issue concerns framing, assumptions, evidence, probe design, restraint, or installation.

## Privacy and security

Do not post secrets, credentials, private customer information, health records, or proprietary data in a public issue. Use a minimal redacted example. For a sensitive report, open a redacted issue requesting a private contact channel.

## Scope

Support covers the plugin package and the open-source skill definitions. It does not include guaranteed consulting, professional advice, custom research, or a service-level agreement.
